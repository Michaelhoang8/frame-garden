Paging model

This model starts empty. Each miss loads one page. A dirty page writes back when evicted; dirty pages still resident at the end are counted separately, without a forced flush.

Clock uses one reference bit per frame. The hand clears set bits until it finds a victim. The offline optimum knows the entire future trace and minimizes faults, not writebacks.

This is an educational demand-paging model, not a hardware benchmark. It does not model TLBs, prefetching, disk latency, or real operating-system performance.
